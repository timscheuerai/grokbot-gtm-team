# The rules that keep the team safe

13 Bots with access to your inbox, your GTM platform and your social accounts need a few hard rules. These are already in every Bot's instructions.

## 1) Nothing goes out without my yes

No Bot sends, posts, enrolls, launches, pays for or deletes anything without my explicit yes on that exact item. Drafts are the default output everywhere.

## 2) Spend is gated

Every outbound campaign runs on a contract from the Outbound Lead: goal, ICP, offer, campaign code, list size, and a spend and lead-count gate. Bots estimate credits before any paid lookup and stop at the gate.

## 3) Each Bot names its connectors

Grok Bot has no per-Bot connector switch: once you connect Gmail, every Bot could use it. So each Bot's instructions end with the only connectors it may use, and the Chief of Staff holds the team to it.

| Bot | Connectors |
|---|---|
| Chief of Staff | What the unit of work needs, plus Claude Code and Codex |
| Outbound Lead | GTM platform CLI, Notion, Slack read only |
| Lead Sourcer | GTM platform CLI, X read tools, web search, Notion when asked |
| Outbound Copywriter | Second brain repo, GTM platform CLI read only, Notion when asked |
| Sequences & Deliverability | GTM platform CLI only, Notion for notes |
| Social Engagement | GTM platform CLI, X read tools |
| Reply Manager | GTM platform inbox, second brain repo |
| Deal Reactivation | Notion, Gmail and Calendar read only, Slack read only, GTM platform CLI |
| Head of Content | X read tools, Notion, GitHub, Google Drive, second brain repo, web search |
| LinkedIn Writer | Notion, GitHub, second brain repo |
| X Writer | X read tools, GitHub, second brain repo |
| YouTube Writer | Google Drive, GitHub, Notion, second brain repo |
| Graphic Designer | Google Drive, GitHub, second brain repo |

## 4) Department heads route, they don't execute

The Outbound Lead and the Head of Content plan, assign and gate. When they start doing the work themselves, the lane gets messy fast.

## 5) Keep routines rare

I started with 10 scheduled routines and now run 1: the Outbound Lead's rollup every weekday at 08:20. A routine earns its place only if you read what it produces every time.
